# 回波位移、五帧导数偏差与平面膨胀速度

本实验延续 [动态验证](DYNAMIC_VALIDATION.md) 中固定五帧、半窗口 \(H=0.2\) s、60 ps FWHM 仪器响应的场景。慢时间记为 \(t\)，快时间记为 \(s\)。目的有两个：量化单个回波在窗口内移动 \(|u|H\) 对中心导数估计的影响；保持同一个平面 S 形物体和正的点权重，提高膨胀速度，看原始瞬态导数是否出现轴向场景的同量级偏差。

运行：

```powershell
python -m transient_transform.speed_expansion_study
```

结果保存在 `results/planar_speed_study/`，包括完整数值 `report.json`、曲线 `planar_speed_bias.png`/`.svg`。每个速度的物理前向帧被缓存，以便重复核查。

## 单回波的相对误差

先固定幅度，令单个光路的回波为

\[
f(t,s)=a h(s-q_0-ut),\qquad
h(x)=\exp[-x^2/(2\sigma^2)],\qquad
d(s)=\partial_t f(0,s)=-au h'(s-q_0).
\]

\(u=q'(0)\) 的单位是“快时间位移/慢时间”；对共焦点响应，\(u=2\hat{\boldsymbol r}\cdot\boldsymbol v/c\)。它是速度沿该条光路的投影，并非空间速度的模。仪器响应 FWHM 为 60 ps 时，\(\sigma=60/[2\sqrt{2\ln2}]\approx25.48\) ps。

在对称慢时间 \(t_i=H\alpha_i\)、\(\alpha=(-1,-1/2,0,1/2,1)\) 上，以带截距的最小二乘拟合中心斜率。记 \(b_i=\alpha_i/\sum_j\alpha_j^2\)、\(\eta=|u|H/\sigma\)，则

\[
\widehat d(s)=\sum_i\frac{b_i}{H}f(t_i,s),\qquad
E(\eta)=\frac{\|\widehat d-d\|_{L^2(ds)}}{\|d\|_{L^2(ds)}}.
\]

高斯脉冲的内积 \(\langle h(\cdot-a),h(\cdot-b)\rangle=\sqrt\pi\sigma\exp[-(a-b)^2/(4\sigma^2)]\)。代入得到 **连续快时间、单回波、幅度恒定、回波中心匀速移动时的精确值**：

\[
E^2(\eta)=1+\frac{2}{\eta^2}\sum_{i,j}b_i b_j
\exp\!\left[-\frac{\eta^2(\alpha_i-\alpha_j)^2}{4}\right]
-2\sum_i b_i\alpha_i
\exp\!\left[-\frac{\eta^2\alpha_i^2}{4}\right].
\]

对小位移，泰勒展开的偶次项被对称拟合抵消，首项为

\[
\widehat d-d=-\frac{u^3H^2}{6}
\frac{\sum_i\alpha_i^4}{\sum_i\alpha_i^2}\,a h'''(s-q_0)
+O(H^4),
\qquad
E(\eta)=\frac{\sqrt{15}}{12}
\frac{\sum_i\alpha_i^4}{\sum_i\alpha_i^2}\eta^2+O(\eta^4)
\approx0.27434\eta^2+O(\eta^4).
\]

其中 \(\|h'''\|/\|h'\|=\sqrt{15}/(2\sigma^2)\)。因此这里起作用的是 **位移与脉冲宽度之比** \(\eta\)，不是独立的空间速度阈值。例如 \(\eta=0.5,1,2,3,4\) 时，精确相对误差依次约为 6.58%、23.38%、62.45%、85.47%、94.24%。在 \(H=0.2\) s 下，\(\eta=1\) 对应径向速度约 0.0191 m/s。这个换算仅针对上述 60 ps 响应和共焦光路。

若 \(a(t)\)、\(q(t)\) 非线性，斜率截断误差的一般首项是 \(H^2(\sum\alpha_i^4/6\sum\alpha_i^2)\,\partial_t^3 f(0,s)\)；其中包含幅度变化、\(q''\)、\(q'''\) 及回波位移项。多个光路叠加后还可能互相抵消，故不能仅把平均 \(\eta\) 代入单脉冲公式预测整幅瞬态的相对误差。LCT 也会改变误差和真导数的空间权重：\(\|L(\widehat d-d)\|/\|Ld\|\) 不必等于原始瞬态误差。

## 物理前向模型的速度扫描

保持 64×64 个墙点、512 个 16 ps 时间箱、相同五帧时间、单层 S 形点集、固定点反射权重与中心曝光量。每个点作平面径向匀速运动；重新计算每个墙点的往返飞行时间、\(r^{-4}\) 幅度及时间箱积分高斯响应。下表无噪声误差均以**解析的中心瞬时导数**为参考：先在原始瞬态测一次，再经相同的有符号作者 LCT 测一次。

| 最外点速度 (m/s) | 加权平均半窗回波位移 (ps) | 原始瞬态相对偏差 | LCT 后相对偏差 |
| ---: | ---: | ---: | ---: |
| 0.08 | 14.8 | 11.4% | 9.4% |
| 0.16 | 29.7 | 31.7% | 28.1% |
| 0.24 | 44.9 | 50.4% | 46.4% |
| 0.32 | 60.3 | 64.4% | 60.8% |
| 0.40 | 75.9 | **74.1%** | **71.4%** |
| 0.48 | 91.9 | 81.6% | 79.3% |

先前轴向三层 S 场景最外点速度为 0.08 m/s，原始瞬态偏差 **75.7%**，LCT 后 **58.0%**。其中两层活动点的加权平均半窗回波位移约 **98.3 ps**；中心层静止，若一起加权则约 49.8 ps。平面场景在 0.40 m/s 时，原始瞬态偏差达到相近的 74.1%，说明“平面运动不会产生明显导数失效”并不成立。两种运动的 \(h'\) 均有正负双峰；平面低速实验的双峰只是在窗口内移动较少。

0.40 m/s 平面实验的 12 组独立泊松计数给出 LCT 后总相对误差 RMS **71.49%**，仅计噪声的 RMS **3.68%**，因此此时主要是时间拟合偏差。与原轴向实验 58.33% 的含噪总误差不能逐项对齐：三层和单层的几何、真导数的空间频谱及 LCT 作用均不同。提高平面膨胀速度还使半窗口两端尺度变成约 0.329 与 1.671；所以这不是“仅改变速度而所有形状固定”的方向消融，但它在同一平面场景中直接复现了速度增大导致的大偏差。

这一结果支持以每条光路的 \(|q'|H/\sigma\) 衡量当前有限窗口导数估计的适用性。它不说明 LCT 本身存在硬速度上限；缩短窗口、改变估计模型或直接拟合有限位移回波，都可能处理更快的运动，代价由噪声和可辨识性另行决定。
