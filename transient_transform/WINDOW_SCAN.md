# 二阶拟合的时间窗口扫描

## 问题与实验设计

只用独立物理模拟的匀速平移 S 场景。沿用原版作者 LCT 的固定有符号核心，并以瞬时无噪声 \(L\tau(0)\) 与 \(L\partial_t\tau(0)\) 为误差参考。这测量时间估计离固定 LCT 结果有多远，**不是**物理密度的绝对误差。

从同一个已验证正向缓存取 7 次完整扫描，慢时间间隔固定为模拟的 0.1 秒。取嵌套的中心 3、5、7 帧，半窗口分别为 \(H=0.1,0.2,0.3\) 秒；每个窗口独立做二阶 OLS，输出中心与一阶导数。保持测量几何、仪器响应、速度、LCT 正则化和同一瞬时误差目标不变。

并列报告两种预算：

1. **每帧曝光固定为 1**：窗口越长，完整扫描及总光子数越多。每组噪声实验的短窗口是同组长窗口的帧子集。
2. **总曝光固定为 7**：窗口有 \(N\) 帧时每帧曝光 \(7/N\)，比较相近总光子预算下的时间跨度。不同窗口需要各自采样 Poisson 计数。短窗口下更长的单帧曝光在真实硬件上可能带来扫描内运动模糊；本模拟仍按每次扫描静止处理。

每帧 \(Y_i\sim\mathrm{Poisson}(e_i\mu(t_i))\)。记录无噪声窗口估计的时间偏差、相对该估计的噪声 RMS、相对瞬时目标的总 RMS。所有指标在完整有符号体积上计算，使用原版 LCT 单位；未裁剪负值。

## 为什么没有通用最优窗口

记 \(w_{ki}(H)\) 为二阶拟合的中心（\(k=0\)）或斜率（\(k=1\)）权重，\(L\) 为固定线性空间逆。对每个系数，相对于瞬时 LCT 目标的平方误差期望分解为

\[
\mathrm{MSE}_k(H)=\left\|L\sum_iw_{ki}(H)\mu(t_i)-L\mu^{(k)}(0)\right\|^2
+\sum_i\frac{w_{ki}(H)^2}{e_i}
\left\|L\operatorname{diag}\!\left(\sqrt{\mu(t_i)}\right)\right\|_F^2.
\]

第一项是时间模型的偏差，第二项是 Poisson 噪声经固定 LCT 后的方差。对称、平滑轨迹的二阶中心拟合偏差领先阶为 \(O(H^4)\)，中心斜率偏差为 \(O(H^2)\)。缩短窗口降低这两种偏差，但使斜率权重增大。在固定扫描间隔和固定每帧曝光下，扫描数约随 \(H\) 增加，中心与斜率噪声方差的粗略尺度分别为 \(H^{-1}\) 和 \(H^{-3}\)。系数取决于轨迹、光子通量、仪器响应、空间逆和曝光预算；因此不能给出不依赖场景及硬件的数值最优窗口。

真实硬件还需要知道完成一次扫描的时长、相邻扫描的最小间隔、每个墙面采样点的时刻和可用曝光。若一次扫描期间物体已经明显移动，每帧对应一个静止 \(\rho(t_i)\) 的假设便需修改。这里的 0.1 秒间隔是模拟参数，**不是**可实现的硬件下限。

例如斜率偏差领先阶为 \(aH^2\)。若每帧曝光固定且扫描间隔固定，粗略风险函数为 \(a^2H^4+cH^{-3}\)，其内部驻点为 \(H=(3c/4a^2)^{1/7}\)。若总曝光固定，噪声尺度更接近 \(cH^{-2}\)，对应驻点为 \(H=(c/2a^2)^{1/6}\)。这些只是局部平滑轨迹和足够多帧下的尺度关系；\(a,c\) 未知，短窗口只有 3 帧时更不能把连续近似当成数值答案。

## 实验结果（2026-10-31）

默认 12 组随机序列。表中为中心状态 / 一阶导数的**总相对 RMS**，均相对同一瞬时无噪声 LCT 目标。

| 半窗口 H | 扫描数 | 固定每帧曝光 | 固定总曝光 |
| ---: | ---: | ---: | ---: |
| 0.1 s | 3 | 4.400% / 27.820% | 2.880% / 18.373% |
| 0.2 s | 5 | 3.065% / **15.018%** | 2.598% / **13.503%** |
| 0.3 s | 7 | **2.583%** / 17.110% | **2.584%** / 17.104% |

无噪声时间偏差依次为：中心 0%、0.122%、0.466%；导数 2.777%、8.496%、15.413%。导数在两种预算下都以已测的 0.2 秒半窗口最好，说明这里有明确的偏差与噪声折中。中心状态在已测范围内仍随窗口增长而改善；固定总曝光时 0.2 与 0.3 秒的差距很小，仅凭 12 组随机序列不应声称精确最优值。0.3 秒也是本次扫描边界，不能推出更长窗口会怎样。

这组实验同时改变了窗口跨度和扫描数，符合固定扫描间隔下的嵌套采样。固定总曝光控制了总光子预算，仍不能消除扫描数变化造成的拟合权重差异。若需要纯粹隔离时间跨度，应另做固定扫描数、改变扫描间隔的实验；那会对应不同的硬件时序假设。

## 速度敏感性：0.2 秒是否为通用甜区

保持 S 形几何、中心位置、墙面、仪器响应、光子增益、LCT 参数、7 次扫描时刻及窗口选择不变，仅把匀速平移速度改为 0.04 和 0.16 m/s，与原来的 0.08 m/s 对照。新时刻的 transient 由同一个独立飞行时间正向模型精确计算；空间位置与原速度缓存重合的帧直接复用，并按速度比例变换中心解析导数。每种速度各用 12 组 Poisson 序列。0.08 m/s 采用先前完成的 12 组报告；另外两种速度使用可恢复的分批随机采样，三者的随机样本并非逐个配对。

以下为**一阶导数总相对 RMS**，每行粗体是该速度下已测三个窗口的最低值：

| 速度 | 固定每帧曝光：H=0.1 / 0.2 / 0.3 s | 固定总曝光：H=0.1 / 0.2 / 0.3 s |
| ---: | ---: | ---: |
| 0.04 m/s | 55.456% / 24.934% / **15.530%** | 36.254% / 21.126% / **15.569%** |
| 0.08 m/s | 27.820% / **15.018%** / 17.110% | 18.373% / **13.503%** / 17.104% |
| 0.16 m/s | **17.051%** / 26.115% / 39.972% | **13.432%** / 25.927% / 39.981% |

因此，即使形状完全不变，已测最佳导数窗口也随速度从 0.3 → 0.2 → 0.1 秒移动。三个值都是离散候选中的最低值；0.04 与 0.16 m/s 的最低点位于扫描边界，不能认为已经确定连续最优窗口。中心状态与导数也未必共用同一窗口：例如 0.16 m/s 下，中心状态在已测窗口中以 0.2 秒较好，而导数偏好 0.1 秒。合并曲线见 `results/window_scan/speed_comparison.svg`，本机也生成 PNG；各速度的详细图与报告位于 `results/window_scan/speed_004/`、根目录及 `speed_016/`。

纯平移可写成 \(\mu_v(t)=f(vt)\)。在局部平滑范围内，导数的**相对**时间偏差约随 \(v^2H^2\) 增长，而相对噪声大致随 \(1/(|v|\sqrt{\sum_i e_i t_i^2})\) 下降。因此速度越快，延长窗口带来的模型偏差越早超过降噪收益；速度越慢，导数信号变弱，往往需要更长时间基线。上述实验直接显示了这种迁移，但并未确定不同形状、遮挡或真实硬件下的通用窗口。

复现速度对比：

```powershell
python -m transient_transform.window_scan --speed 0.04 --output transient_transform/results/window_scan/speed_004
python -m transient_transform.window_scan --speed 0.16 --output transient_transform/results/window_scan/speed_016
python -m transient_transform.window_scan --compare-speeds
```

在内存受限的机器上，可给各速度的实验命令加 `--max-new-trials 1` 或 `3` 并重复运行；程序逐组保存进度，直到达到默认 12 组。合并 SVG 总能由 Matplotlib 生成，安装了 `rsvg-convert` 时还会生成 PNG。

## 复现

```powershell
python -m transient_transform.window_scan
```

程序复用已验证的平移正向缓存；缓存缺失时按原模拟器重新生成。默认 12 组独立噪声序列、2 个 CPU 线程。结果在 `results/window_scan/` 的 `report.json`、`window_scan.png` 和 `window_scan.svg`。
