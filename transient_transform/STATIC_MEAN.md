# LTAI 静态平均估计验证

分支：`research/transient-transform`。本轮只验证静态均值，不估计慢时间变化率。

## 实验边界

原版数据没有重复扫描序列。使用作者 S/U 与漫反射 S 的准备后直方图，固定为经验期望瞬态 \(\mu\)，模拟独立重复曝光：

\[
Y_n\mid\mu\sim\operatorname{Poisson}(e_n\mu),\qquad
\hat\mu=\frac{\sum_nY_n}{\sum_ne_n}.
\]

曝光系数相对于这份作者测量的曝光归一化。数据按原版约定校正、降采样、屏蔽早期箱，输出网格为 64×64×512；没有引入新的物理正向模拟器。

这里的经验期望本身来自一次真实测量，包含原始噪声、背景和原版重建偏差。本实验的误差参考是 \(v_\star=L\mu\)，不是隐藏场景的无噪声物理密度。重复抽样不会消除被固定在 \(\mu\) 中的原始误差。

## 原版与新版本

全部使用已与作者 MATLAB 对齐的固定 LCT 参数。

| 结果 | 计算 |
| --- | --- |
| 原版参考 | \(v_\star=L\mu\) |
| 原版单次曝光 | \(v_1=L(Y_1/e)\) |
| LTAI 静态平均 | \(v_N=L\hat\mu\) |
| 相同总曝光原版对照 | \(L[(\sum_nY_n)/(Ne)]\)，与新版本使用完全相同的记录光子 |

最后一行与新版本在静态场景下代数等价。这是曝光预算的校验，不是一个独立降噪算法。

默认 N=7、每帧 e=1，因此新版本相对单帧使用 7 倍的期望光子数。静态平均没有超出相同总曝光原版 LCT 的额外优势。

## 理论预期与判据

在固定线性 L、等曝光 e、独立计数的条件下：

\[
\mathbb E\hat\mu=\mu,\qquad
\operatorname{Cov}(\hat\mu)=\frac{\operatorname{diag}(\mu)}{Ne},
\]

\[
\operatorname{Cov}(L\hat\mu)
=\frac1N\operatorname{Cov}[L(Y_1/e)].
\]

因此输出噪声能量应缩减至 1/N，RMS 应缩减至 \(1/\sqrt N\)，条件输出 SNR 应增加 \(10\log_{10}N\) dB。对 N=7，分别是 0.142857、0.377964 和 8.451 dB。

自动验证包括：

1. 将每帧输入设为期望计数 eμ，检查无噪声平均与 μ 一致、重建与原版参考一致。
2. 检查同一批光子下，LTAI 均值与归一化总计数的原版重建一致。
3. 用 16 组独立序列估计输入和输出噪声能量比例，检验是否符合 1/N。
4. 如果本机存在完整 MATLAB 参考，重新核对原版参考的各数值阶段；缺少时明确标记，不能声称已完成 MATLAB 对照。

Monte Carlo 的两种结果共享序列内的第一帧。报告用配对误差能量及 delta method 估计比例标准误，给出近似 95% 区间；自动判据为理论比例与实测比例差不超过 4 个标准误加理论值的 2%。这不是密度重建精度的阈值。

所有误差都在完整、有符号的原生体积上计算。只在绘图时使用作者的非负截断、翻转和裁剪；同一场景所有图使用参考体积的公共灰度上限，没有逐图拟合增益。展示固定种子的第一组序列，不按图像质量挑选。

## 复现

```powershell
python -m transient_transform.static_mean
python -m unittest discover -s transient_transform/tests -v
```

可调整参数，例如：

```powershell
python -m transient_transform.static_mean --frames 7 --exposure 1 --trials 16 --seed 20261030 --threads 2
```

默认输出到 `results/static_mean/`：

| 文件 | 内容 |
| --- | --- |
| `scene_*/comparison.png`、`.svg` | 参考、原版单帧、LTAI 平均的三视图比较 |
| `scene_*/observations.npz` | 经验期望瞬态、第一帧计数、总计数、估计均值与曝光参数 |
| `scene_*/reconstruction.npz` | 三种有符号原生体积 |
| `noise_scaling.png`、`.svg` | 输出噪声能量缩放及理论对照 |
| `report.json` | 固定来源、参数、MATLAB 锚点、无噪声等价性、曝光对照、逐次 Monte Carlo 误差和通过状态 |

`StaticMeanEstimator` 流式累加计数与曝光，内存不随帧数增加。测试覆盖不同曝光的归一化、独立 Poisson 样本的均值/方差、输入存储独立性和非法帧处理。

## 本机验证记录（2026-10-30）

默认参数：N=7、e=1、16 组序列、seed=20261030。两组场景的完整 MATLAB 参考均已核对，全部检查通过。以下误差是在完整有符号体积上相对于固定原版参考的 Monte Carlo RMS，不是真实密度误差。

| 场景 | 单帧相对 RMS | 7 帧平均相对 RMS | 输出噪声能量比 | SNR 增益 |
| --- | ---: | ---: | ---: | ---: |
| s_u | 23.6292% | 8.9281% | 0.142766 | 8.4538 dB |
| diffuse_s | 45.3217% | 17.1201% | 0.142692 | 8.4560 dB |

两组场景的无噪声均值误差、无噪声重建误差及相同记录光子下的原版/新版本重建差异均为 0。理论噪声能量比为 1/7≈0.142857。

10 项测试通过，其中 6 项为原版 MATLAB 冻结参考验证，4 项为静态均值统计及曝光处理验证。时间变化率尚未验证。
