# 有限位移模型与时间导数拟合的受控比较

本实验回答一个具体问题：五帧二阶拟合得到的斜率在快速膨胀时已明显偏离瞬时导数；如果不把它直接当导数，而是用**同一个五帧拟合算子作用于运动模板**，是否仍可从斜率反推运动？与直接拟合完整五帧相比又损失多少？

```powershell
python -m transient_transform.finite_motion_comparison
```

生成 `results/finite_motion_comparison/report.json` 与 `comparison.png`/`.svg`。原始物理帧使用之前的 0.08、0.40 m/s 平面膨胀缓存；另外独立生成 0.37 m/s 的离网格物理帧。

## 相同数据、三种处理

输入为同一场景在 \(t=(-0.2,-0.1,0,0.1,0.2)\) s 的原生 64×64×512 瞬态，单个时间箱宽 16 ps，仪器响应 FWHM 为 60 ps。把 S 形点集、每点正反射权重、膨胀中心、各点相对膨胀方向和仪器响应作为**已知先验**；需要估计的只有全局最外点速度 \(v\) 和一个公共非负幅度 \(g\)。使用覆盖完整墙面的 16×16 个墙点和快时间箱 190–349 匹配；速度候选为 0.02 至 0.50 m/s，间隔 0.02 m/s。0.08 和 0.40 m/s 在候选格点上，0.37 m/s 不在。

对候选速度 \(v\)，用独立点传播模型算五帧响应 \(a_i(v)\)。令 \(P\) 从慢时间上去掉逐墙点、逐快时间箱的常量，\(w_i=t_i/\sum_jt_j^2\)。对照方法为：

1. **当前 OLS 导数**：\(d_{\rm OLS}=\sum_iw_iY_i\)，直接进入有符号原版 LCT。
2. **有限窗口斜率模板**：匹配 \(k_v^{\rm slope}=\sum_iw_i a_i(v)\) 与同一个 \(d_{\rm OLS}\)。模板自身包含大位移和五帧拟合造成的形状变化。
3. **完整五帧模板**：匹配 \(k_v^{\rm full}=P(a_i(v))_i\) 与 \(P(Y_i)_i\)。

后两者都对每个候选速度单独求非负最小二乘幅度 \(\hat g_v=[\langle k_v,Y\rangle_W]_+/\|k_v\|_W^2\)，选择加权残差最低的速度，然后由该运动模型**解析计算中心时刻的瞬时导数**。权重 \(W=1/\max(1,\bar Y_{\rm clean})\) 对各方法相同；这里使用无噪声期望求权重，属于受控实验中的先验，时间去均值后的泊松噪声相关性未作严格似然处理。报告同时保留幅度已知的对照，但下表使用更严格的**幅度未知、共同拟合**结果。

所有方法的导数误差均相对于独立物理模拟器给出的解析 \(\partial_t\tau(0)\)；LCT 后则相对于同一个 \(L\partial_t\tau(0)\)。这衡量时间模型误差，不衡量 LCT 重建真实密度的空间误差。

## 结果

下表为 LCT 后相对误差。含噪值是相同 12 组独立泊松五帧序列的 RMS；模板方法将估计的 \(\hat g,\hat v\) 代回已知 S 形模型，原 OLS 方法直接对整幅 64×64×512 斜率做 LCT。

| 真速度 | OLS 无噪声 / 含噪 | 有限斜率模板 无噪声 / 含噪 | 完整五帧模板 无噪声 / 含噪 |
| ---: | ---: | ---: | ---: |
| 0.08 m/s | 9.44% / 15.84% | <0.01% / **0.42%** | <0.01% / **0.44%** |
| 0.37 m/s，离网格 | 67.84% / 67.90% | **0.70% / 0.75%** | **0.35% / 0.40%** |
| 0.40 m/s | 71.44% / 71.47% | <0.01% / **0.17%** | <0.01% / **0.15%** |

进入 LCT 前的**无噪声** OLS 导数误差依次为 11.38%、70.87%、74.14%；有限斜率模板依次为 <0.01%、0.70%、<0.01%，完整五帧模板为 <0.01%、0.35%、<0.01%。模板法在本实验中只调整已知中心导数形状的公共标量 \(gv\)，所以它的相对误差经过同一个线性 LCT 后数值不变；OLS 的误差形状较复杂，前后误差不同。完整的含噪原始瞬态误差也保存在 `report.json`。

在 0.08、0.40 m/s 的 12 组含噪数据中，两种模板方法每次都选中真速度所在的候选格点。0.37 m/s 的无噪声数据中，两者都选中相邻的 0.38 m/s；拟合幅度补偿一部分离网格导数误差。格点选择一致不表示速度没有不确定性，尤其考虑 0.02 m/s 的候选间距。

## 推论及边界

**五帧斜率不是瞬时导数，但在这个低维先验下并未丢掉辨认速度所需的全部信息。** 对斜率匹配正确的有限窗口模板，也能消除原 OLS 方法的大部分时间模型偏差。完整五帧在离网格场景的导数误差较小，但本实验不能推断其在一般形变中一定优于斜率模板。

这个结果依赖很强的受控条件：整个 S 形几何与点反射权重已知、所有点共享一个膨胀率、正向模拟器与生成数据的 IRF/光路一致、没有遮挡或扫描内运动。格点上的无噪声近零误差首先是同一物理模型的自洽检查，**不是**从未知瞬态恢复未知 \(\rho\) 与完整速度场。小于 1% 的含噪误差也有先验形状、全局参数共享和大量墙点/光子的帮助。下一层问题是放开形状与局部速度、评估模板相干性和多点串扰；仅这一步尚不能判定完整五帧是否值得比斜率表示多付出的计算和存储代价。
